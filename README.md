> 🚧 **Repositorio en preparación.** Lo iré llenando durante el próximo semestre, cuando empiece a dar las monitorías de Lógica de Programación.

## 🎯 Objetivo

Reunir en un solo lugar el material de las monitorías de **Lógica de Programación**: explicaciones cortas, ejercicios resueltos y talleres de práctica, con cada solución escrita en **Python** y en **Java**. Así se puede comparar cómo se expresa la misma idea en cada lenguaje y practicar con el que pida el curso.

> 👨‍💻 **Monitor:** Thomas Sining Salazar · Ingeniería de Sistemas e Informática

## 🧭 Temas previstos

La lista es tentativa y se ajustará al programa oficial del curso.

| # | Tema | Qué se practica |
|---|---|---|
| 1 | Introducción y pensamiento algorítmico | Qué es un algoritmo, entradas, procesos y salidas, pseudocódigo y diagramas de flujo. |
| 2 | Variables, tipos de datos y operadores | Declaración, conversión de tipos, operadores aritméticos, lógicos y de comparación. |
| 3 | Condicionales | `if`, `else`, `elif` / `else if`, condiciones anidadas y `switch` / `match`. |
| 4 | Ciclos | `for`, `while`, contadores, acumuladores y ciclos anidados. |
| 5 | Funciones y métodos | Parámetros, retorno, alcance de variables y descomposición de problemas. |
| 6 | Arreglos y listas | Recorrido, búsqueda, ordenamiento básico y matrices. |
| 7 | Cadenas de texto | Manipulación, recorrido y validación de texto. |
| 8 | Depuración y pruebas | Cómo leer errores, seguimiento paso a paso y casos de prueba. |

## 🗂️ Estructura planeada

```text
monitorias-logica-programacion/
├── README.md
├── 01-introduccion/
│   ├── README.md          # explicación del tema y enunciados
│   ├── python/
│   └── java/
├── 02-variables-y-operadores/
│   ├── README.md
│   ├── python/
│   └── java/
├── ...                    # una carpeta por tema, con la misma forma
├── talleres/              # talleres de práctica y simulacros de parcial
└── recursos/              # guías, cheat sheets y enlaces útiles
```

Cada tema tendrá:
- 📄 un `README.md` con la explicación y los enunciados de los ejercicios,
- 🐍 las soluciones en `python/`,
- ☕ las mismas soluciones en `java/`.

## ▶️ Cómo ejecutar los ejemplos

Cuando estén publicados, se ejecutarán así:

```bash
# Python (3.10 o superior)
python ejercicio.py

# Java (JDK 17 o superior)
javac Ejercicio.java
java Ejercicio
```
